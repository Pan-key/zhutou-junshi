# 猪头军师 (PigTou JunShi)

微信聊天回复辅助工具 —— 读到对方消息，本地 AI 判断风险，狗头军师深度推演利弊，给你 3 条候选回复，你选一条填入微信输入框，**发送永远手动**。

## 截图

![粉色UI](docs/ui_home.png)

## 特点

- **零 API 成本**：本地 Laya 模型做风险初判，本地 qwen2.5:7b 起草回复，不花一分钱
- **狗头军师模式**：不是机械回复，按"稳健 / 策略 / 边界"三个方向推演利弊
- **不碰微信进程**：只截图 + 本地 OCR，不 hook、不注入、不读数据库
- **全内置离线包**：Ollama 运行时 + 两个模型随程序打包，**解压即用，双击就跑**，不装任何东西
- **粉色 UI**：干净的悬浮窗，不打扰

## 下载

去 [Releases](../../releases) 下载 `zhutou-junshi-v1.0.0-full.zip`（约 6~9GB，含全部模型），解压后双击 `猪头军师.exe`。

不需要安装 Ollama，不需要下载模型，不需要填任何 API key —— 全在包里。

## 首次使用

1. 解压发布包（**整个文件夹**解压出来，别只拿 exe，模型和运行时在它旁边）
2. 双击 `猪头军师.exe`
3. 打开微信窗口，等悬浮窗提示"本地模型引擎已就绪"即可开始

首次启动会自动拉起内置模型引擎（几秒），之后完全离线。

## 系统要求

- Windows 10/11 64位
- 内存 8GB 以上（推荐 16GB）
- 硬盘空间 12GB 以上（发布包 6~9GB + 解压后运行占用）
- 不要求独立显卡（CPU 也能跑，稍慢）；NVIDIA 显卡自动走 CUDA 加速

## 配置说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 判断模型 | 本地 Laya | 随包内置，离线免费 |
| 起草模型 | qwen2.5:7b | 随包内置，Ollama 运行时自动拉起 |
| 军师模式 | 开启 | 利弊推演 + 三版本回复 |

也可以去设置里把判断/起草换成云端（OpenRouter / DeepSeek / OpenAI 等），填对应 key 即可。

## 工作原理

```
微信消息 → 截图 OCR → Laya 本地风险初判
                    ↓
      qwen2.5:7b（随包 Ollama）→ 狗头军师利弊推演
                    ↓
      3 条候选（稳健/策略/边界）→ 填入微信输入框 → 人工确认发送
```

## 开发者构建

```bat
build.bat
```

一条命令完成：建 venv → 装依赖 → 从本机 Ollama 复制运行时和 qwen2.5:7b → 下载 Laya 快照 → PyInstaller 打包。产物在 `dist\猪头军师\`，整个文件夹即发布包。
